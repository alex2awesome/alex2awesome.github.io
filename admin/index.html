Enter the password you chose for this browser.

For the site's owner: this browser takes a GitHub access token, once.

  1. Create a fine-grained access token on GitHub with:
    • Repository access: Only select repositories, then , and
    • Permissions, Repository permissions, Contents: Read and write

The token stays in this browser, encrypted with the password; you will be asked for the password each time you open the editor. It is sent only to GitHub. You can revoke it on GitHub at any time.
